# 爬虫采集模块设计

> **架构更新**：爬虫模块已改为 Skill 插件形式。详见 [06-Skill采集架构.md](06-Skill采集架构.md)。
>
> 本文档保留 CrawlerRunner 的爬虫细节设计（HumanSimulator / ContentExtractor / robotsChecker），但运行时接口已统一为 `CollectorSkill`。

## 一、定位

爬虫采集以 **web-crawler Skill** 的形式安装到天工引擎中：

```
采集源类型（SourceConfig.skillId）:
├── claude-code       ← Claude Code 直接生成（已实现，迁移至 Skill）
├── web-crawler       ← 爬虫抓取公开网页 → AI 整理（本模块，Skill 形式）
├── wikipedia-api     ← Wikipedia API 拉取（预留 Skill）
├── arxiv-fetcher     ← arXiv 论文采集（预留 Skill）
└── ...               ← AI 可自行设计安装任意 Skill
```

**核心原则**：爬虫只负责"取"，AI 负责"整理"。原始 HTML 经由 Claude 提炼为标准化 YAML frontmatter，再走现有审核→提交管线。

---

## 二、架构

```
CrawlerRunner（单站点采集器）
    │
    ├─ 1. robots.txt 检查 → 提取允许的路径
    ├─ 2. 种子 URL → 浏览器模拟访问（Puppeteer/Playwright）
    │      ├─ 随机延迟 1-5 秒
    │      ├─ 模拟滚动行为
    │      └─ User-Agent 轮换池
    ├─ 3. HTML → 正文提取（Readability / 自定义选择器）
    ├─ 4. 原始正文 → Claude 整理（调用 Claude API）
    │      ├─ 传入 taxonomy 要求
    │      └─ 输出为标准 YAML frontmatter
    ├─ 5. YAML 块 → OutputParser → PendingResourceItem
    │
    └─ 结果汇入 pending 管线（审核→入库→提交）

深度控制：默认 2 层（当前页 + 详情页）
单站并发：1 线程（模拟单人访问）
全局并发：受 CollectorEngine 进程池统一管理
```

## 三、CrawlerRunner 设计

### 3.1 配置结构

```typescript
// electron/collector/crawlerRunner.ts

interface CrawlerSourceConfig extends SourceConfig {
  type: 'crawler'
  crawler: {
    seedUrls: string[]            // 起始 URL
    maxDepth: number              // 最大爬取深度（默认 2）
    maxPages: number              // 单次最大页数（默认 50）
    selectors: {
      title: string               // CSS 选择器：标题
      content: string             // CSS 选择器：正文
      exclude: string[]           // CSS 选择器：排除区域（广告/导航）
    }
    linkFilter: string            // 链接提取规则（正则/选择器）
    requestDelay: [number, number]// 请求间隔范围 [1000, 5000] ms
    respectRobotsTxt: boolean    // 是否遵守 robots.txt（默认 true）
  }
}
```

### 3.2 人类行为模拟

```typescript
class HumanSimulator {
  // 请求间隔随机
  async delay(): Promise<void> {
    const ms = randomBetween(crawlerConfig.requestDelay[0], crawlerConfig.requestDelay[1])
    // 加入高斯噪声（±30% 抖动）
    const jitter = ms * (0.7 + Math.random() * 0.6)
    await sleep(Math.round(jitter))
  }

  // 模拟页面浏览行为
  async simulateBrowsing(page: Page): Promise<void> {
    // 随机滚动 2-4 次
    const scrolls = 2 + Math.floor(Math.random() * 3)
    for (let i = 0; i < scrolls; i++) {
      const scrollY = 200 + Math.random() * 800
      await page.evaluate((y) => window.scrollBy({ top: y, behavior: 'smooth' }), scrollY)
      await sleep(400 + Math.random() * 800)
    }
    // 回到顶部
    await page.evaluate(() => window.scrollTo({ top: 0, behavior: 'smooth' }))
    await sleep(300)
  }

  // User-Agent 轮换池
  getUserAgent(): string {
    const pool = [
      'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 Chrome/131.0.0.0',
      'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 Edge/131.0.0.0',
      'Mozilla/5.0 (Macintosh; Intel Mac OS X 14_7) AppleWebKit/605.1.15 Safari/605.1.15',
    ]
    return pool[Math.floor(Math.random() * pool.length)]
  }
}
```

### 3.3 正文提取

```
HTML 正文提取策略（优先级从高到低）:

1. 用户自定义 CSS 选择器（最精准）
   crawler.selectors.content → document.querySelectorAll()

2. Readability 算法（通用性好）
   @mozilla/readability → 自动识别正文区域

3. 回退策略（去标签纯文本）
   正则移除 script/style/nav/footer → body.innerText
```

提取的原始正文送入 Claude 进行结构化：

## 四、安全边界

### 4.1 硬约束（不可关闭）

| 约束 | 实现 |
|------|------|
| **robots.txt** | 抓取前检查，禁止的路径直接跳过 |
| **不登录** | 不处理 cookie/session 认证 |
| **不绕过** | 不处理验证码、不模拟登录 |
| **公开信息** | 仅抓取无需认证的公开页面 |
| **限速** | `requestDelay` 最小值硬编码为 1000ms |

### 4.2 软约束（可配置）

| 约束 | 默认值 |
|------|--------|
| 深度上限 | 2 层 |
| 单次页数上限 | 50 页 |
| 重试次数 | 2 次（指数退避） |
| User-Agent | 真实浏览器 UA 池 |
| 并发数 | 单采集源 1 线程 |

### 4.3 合规检查清单

```
抓取前:
  ☐ robots.txt 允许该路径
  ☐ 网站无 Cloudflare/反爬严格保护
  ☐ 内容为公开信息（非登录后可见）
  ☐ 非 paywall/付费墙

抓取中:
  ☐ 请求间隔 > 1000ms
  ☐ 每个页面模拟滚动行为
  ☐ 不提交表单/不点击操作
  ☐ 仅读取，不修改

抓取后:
  ☐ 原始 URL 保留在 YAML source_url 字段
  ☐ 整理后的内容标注"AI 整理自: <来源>"
  ☐ 不重新发布原文（仅发布整理后的结构化摘要）
```

## 五、与现有模块的关系

```
collectorEngine.runSource(sourceId)
    │
    ├─ source.type === 'claude'
    │   └─ ClaudeRunner × N          ← 已实现
    │
    ├─ source.type === 'crawler'     ← 新增
    │   └─ CrawlerRunner × 1
    │       ├─ HumanSimulator
    │       ├─ ContentExtractor
    │       └─ Claude（整理/结构化）
    │
    └─ source.type === 'api'         ← 预留
        └─ ApiRunner

所有 Runner 输出统一:
  → YAML frontmatter 块
  → OutputParser.validateAgainstTaxonomy()
  → pendingResourceStore.addItem()
  → 审核 → 入库 → 提交
```

## 六、新增文件清单

| 文件 | 用途 |
|------|------|
| `electron/collector/crawlerRunner.ts` | 单站点采集器（Puppeteer + Readability + Claude 整理） |
