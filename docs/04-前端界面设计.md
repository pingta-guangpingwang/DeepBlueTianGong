## 三、工坊标签页（从 ResourceMarket.tsx 提取）

完全从驾驭工程的 `ResourceMarket.tsx` 提取以下部分：

### 3.1 保留组件

| 组件 | 说明 |
|------|------|
| 仓库筛选按钮 | 动态渲染（从 repoConfig 读取 visible repos） |
| 类型筛选 | 动态渲染（从 taxonomy.types 读取） |
| 搜索栏 | 全文关键词搜索 |
| 资源卡片列表 | VirtualList 渲染 |
| 资源详情面板 | YAML + 正文展开 |
| 排行榜 | 左侧评分排行 |
| 一键同步按钮 | GitHub 拉取 |
| 中/EN/双语切换 | 语言切换 |

### 3.2 移除组件

| 组件 | 原因 |
|------|------|
| 提交面板（CommitPanel） | 天工是全自动提交，不需要手动按钮 |
| 待审面板（PendingPanel） | 移到独立标签页 |
| 添加提示（AddTipPanel） | 天工通过采集器添加，不是手动 |
| 克隆面板 | 通过配置界面管理 |

## 七、状态管理

不使用 Redux/MobX 等重型库，采用 React Context + useReducer（从 HFContext.tsx 借鉴模式）：

```typescript
// src/context/AppContext.tsx

interface AppState {
  // 资源
  resources: ResourceItem[]
  loading: boolean

  // 待审
  pendingItems: PendingItem[]
  pendingCount: number

  // 采集
  collectorRunning: boolean
  runnerStates: Map<string, RunnerState>
  collectorLog: CollectHistoryEntry[]

  // 配置
  repos: RepoConfig[]
  sources: SourceConfig[]
}

type AppAction =
  | { type: 'SET_RESOURCES'; payload: ResourceItem[] }
  | { type: 'SET_PENDING'; payload: PendingItem[] }
  | { type: 'RUNNER_UPDATE'; payload: { taskId: string; state: RunnerState } }
  | { type: 'COLLECTOR_START'; payload: string }
  | { type: 'COLLECTOR_DONE'; payload: string }
  // ...
```

## 八、性能策略

| 策略 | 实现 |
|------|------|
| **大列表** | VirtualList 对象池渲染（已有） |
| **资源详情** | 按需加载，不预加载正文 |
| **采集日志** | 实时推流，不轮询 |
| **仓库状态** | `getLocalChanges` 3 秒 TTL 缓存（已有） |
| **Manifest** | 内存缓存 + 5 秒防抖重载（已有） |
| **Claude 输出** | 流式解析 YAML 块，不等完整输出 |
